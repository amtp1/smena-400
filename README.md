# Смена 400

Тренажёр проводника ВСМ для трека «Геймификация для ВСМ» хакатона Московского транспорта.

Одна смена — три ветвящихся события с таймером, шкалами лояльности и безопасности, профилем, ачивками и таблицей лидеров.

```bash
docker compose up --build
```

Откроется http://localhost:4000

Локально без Docker:

```bash
npm install
npm run dev
```
